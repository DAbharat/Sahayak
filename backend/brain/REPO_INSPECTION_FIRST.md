# Repository Inspection Instructions

Before coding:
1. Print/list the repository tree.
2. Identify framework and package manager.
3. Find existing API routes.
4. Find existing authentication/config.
5. Find current environment variable conventions.
6. Find existing AI/AWS utilities.
7. Find the frontend pages/components related to chat/voice/schemes/documents.
8. Reuse existing abstractions where possible.
9. Do not overwrite working functionality.
10. Then implement the master prompt in small verified increments.
