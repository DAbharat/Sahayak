# Sahayak Citizen Welfare Portal

Sahayak is a frontend-only React application for discovering government welfare schemes and preparing citizen grievance drafts. Demo accounts and draft generation run locally in the browser; no backend server is required.

## Run locally

**Prerequisite:** Node.js 20.19 or newer.

From the project folder, run these two commands:

```bash
npm i
npm run dev
```
